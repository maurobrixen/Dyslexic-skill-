# 🌌 Skill: `mb-antigravity-ui-designer`
> **Design UI/UX di Livello Premium & Micro-Animazioni Spaziali**

Questa skill fornisce all'Agente le regole di **Design System e UX** per creare componenti d'interfaccia spettacolari, leggibili e ad alte prestazioni, eliminando la genericità dei layout standard.

---

## 🎨 Principi del Design System Antigravity

1. **Palette Cromatiche Curate**: Usa scale HSL con gradienti morbidi (es. `linear-gradient(135deg, #1e0533 0%, #081226 100%)`).
2. **Micro-Animazioni fluide**: Transizioni CSS3 con `cubic-bezier(0.4, 0, 0.2, 1)`, hover effects dinamici e pulse neon sottili per dare vita agli elementi interattivi.
3. **Gerarchia Visiva Inequivocabile**: Titoli grandi con gradienti di testo (`background-clip: text`), card ben distanziate e indicatori visivi di stato immediati.

---

## ⚡ Trigger di Attivazione

Attiva questa skill quando:
- Si creano o modificano file CSS, componenti di interfaccia o layout web.
- L'utente richiede un restyling grafico, ottimizzazione dell'UX o animazioni.
- Occorre migliorare la leggibilità visiva di una dashboard.

---

## 🚀 Esempio di Token CSS & Animazioni

```css
/* Antigravity Design System Tokens */
:root {
  --font-primary: 'Inter', system-ui, sans-serif;
  --color-brand-cyan: #00f0ff;
  --color-brand-purple: #7b2cbf;
  --gradient-glow: linear-gradient(135deg, rgba(0, 240, 255, 0.2), rgba(123, 44, 191, 0.2));
  --transition-smooth: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.interactive-card {
  transition: var(--transition-smooth);
}
.interactive-card:hover {
  transform: translateY(-4px) scale(1.01);
  box-shadow: 0 12px 40px rgba(0, 240, 255, 0.15);
  border-color: var(--color-brand-cyan);
}
```
